# CampusBite

Campus canteen food ordering website.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.

## Important
This version is a front-end demo and stores accounts/orders in browser storage. A production multi-user deployment needs a secure backend/database and server-side authentication.
